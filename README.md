# Login Form Application

## Description
This project is a simple Login Form using Java Servlet and HTML.

The user enters username and password.
The servlet checks the entered values with 3 hardcoded username-password pairs.

If login is successful:
- Welcome message is displayed

If login fails:
- Error message is shown

---

## Technologies Used
- Java
- Servlet
- HTML
- Apache Tomcat v10.1
- Eclipse IDE

## How to Run

1. Open Eclipse
2. Create Dynamic Web Project
3. Add HTML and Servlet files
4. Configure Tomcat Server
5. Run on Server
6. Open browser

URL:
http://localhost:8081/LoginFormApp/
